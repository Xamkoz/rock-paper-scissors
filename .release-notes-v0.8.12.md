## What's new

- **Match-found ticks** — Notification ticks and haptics now stop when the first live round starts, not only when you open the game screen. Fixes lobby alert feedback continuing during active gameplay.
- **Background match launch** — With background usage enabled, the app auto-launches when a match enters the lobby or goes active so you reach pre-game sync or the game screen sooner.
- **Connection status** — Network probes no longer flip the UI to “Checking” on every capability change; reconnect handling is less noisy while staying accurate.
