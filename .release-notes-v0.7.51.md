## What's new

- **Stability** — Safer foreground service start from background, Firebase Auth token refresh no longer crashes on transient network errors, and move/clock sounds use correct MediaPlayer/AudioTrack setup.
- **Firestore** — Stops aggressive `disableNetwork` resets on every network flap (fewer false “offline” WatchStream errors when connectivity is fine).
- **Background queue** — Matchmaking notification updates at most once per second so Android no longer sheds notification 1001; `startForeground` runs only once per service run.
- **Platform** — Predictive back enabled in manifest, Firebase Auth locale set, Play Services package visibility for Google Sign-In, and audio attribution tags for in-game sounds.
